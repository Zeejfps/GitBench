# DiffDino

A desktop Git client for Windows, macOS, and Linux. Review changes, edit files, and
manage your repositories in one place.

## What you can do

- **Manage your Git work:** stage changes, commit, switch branches, merge, rebase,
  and work with stashes, worktrees, and submodules.
- **Review changes:** browse commit history, compare code, preview images and
  Markdown, and mark files as reviewed.
- **Edit and run:** browse and edit files, search your code, and use the built-in terminal.
- **Get optional AI help:** ask about code, draft commit messages, and walk through
  changes. Connect an AI provider or a local model in Settings.
- **Make it yours:** group repositories, choose a light or dark theme, adjust the
  interface size, and customize keyboard shortcuts.

## Install

Download the build for your system from the
[latest release](https://github.com/Zeejfps/GitBench/releases/latest):

- **Windows:** installer or portable build.
- **macOS:** Apple Silicon or Intel build.
- **Linux:** AppImage.

You also need [Git](https://git-scm.com/downloads) installed and available on your
`PATH`. No .NET installation is needed. Installed builds check for updates and let
you restart to apply them.
